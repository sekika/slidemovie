# slidemovie の紹介

- 動画作成を自動化
- Markdown + PowerPoint
- AI ナレーション

::: notes
slidemovie の紹介へようこそ。このツールを使うと、Markdown と PowerPoint を組み合わせて、AI ナレーション付きの動画を自動的に作成できます。
:::

# 仕組み

1. Markdown を書く
2. PPTX を生成
3. デザインを編集
4. 動画を出力

::: notes
プロセスはシンプルです。まず、Markdown で原稿を書きます。次に、PowerPoint ファイルを生成します。PowerPoint のデザイナー機能で見た目を整えたら、コマンド一つで動画をビルドします。
:::
